JAVASCRIPT DASHBOARD - VS CODE PROJECT

HOW TO RUN
1. Extract javascript-dashboard.zip.
2. Open the extracted "javascript-dashboard" folder in Visual Studio Code.
3. Open index.html.
4. Run it in a browser:
   - Recommended: install the "Live Server" extension in VS Code.
   - Right-click index.html and choose "Open with Live Server".
   - Or open index.html directly in Chrome, Edge, or Firefox.

FILES
- index.html  : Page structure
- style.css   : Layout, colors, typography, and responsive styling
- script.js   : Button click interaction

Click the green "Click Me" button to display the JavaScript message.
No additional packages or installations are required.
